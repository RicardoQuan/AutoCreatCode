# 向下整理的线路方向

状态：按用户 2026-10-26 的标图要求实施。

## 确定的行为

- 自循环和返回上游的连接绕左侧；返回上游时从目标下方进入，箭头向上。
- 相邻主流程沿节点水平中心向下连接。前向主流程优先 `0`、`true`、`Succeeded`，不把回边选为主流程。
- 越过中间节点或离开主链的前向跳转绕右侧。同目标、同方向的连接继续共用干线；最后一个主流程节点可以直接进入异常节点。
- 整理只改变布局和线的几何，保留连接对象、状态值、优先级、参数以及全部分支。
- 清除整理前的绝对折点。手动布线在下次点击整理前继续有效；撤销可还原整理前的布局。

## 实现边界

把现有布局算法提取为可独立验证的 `arrangeDownward`，按整理后的坐标和前向后继确定中心、左侧和右侧路线。复用现有画布几何字段保存侧边干线，不新增项目格式。汇流只把真正的前向中心连接当作直连。

来源端口表达几何，`Outcome` 表达状态。加载时保留明确的布尔状态；仅旧数据缺少有效状态时按传统端口补齐。出口按钮随整理后的实际来源端口显示，数值 `0` 保持居中。
